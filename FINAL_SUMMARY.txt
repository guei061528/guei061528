================================================================================
KEY FEATURES
================================================================================

1. Intelligent Degrade Detection
   - Automatically detects PASS → FAIL transitions
   - Compares failure reasons using normalized MD5 hash
   - Case-insensitive, whitespace-normalized comparison

2. Smart JIRA Management
   - Adds [DEGRADE] marker to titles
   - Adds 'degrade' label to issues
   - Prevents duplicate JIRAs for same failures
   - Comments on existing JIRAs with new version info

3. Persistent History Tracking
   - Stores test results in ~/.jira_test_history.json
   - Tracks: result, version, DB, fail hash, JIRA key
   - Survives system restarts and script re-runs

4. Complete Integration
   - Works with existing JIRA creation flow
   - Supports flaky test detection
   - Handles all existing features
   - Backward compatible

DEGRADE SCENARIOS
================================================================================

Scenario 1: Initial Degrade (PASS → FAIL)
  V807: PASS
  V808: FAIL
  → CREATE JIRA: [DEGRADE][MA][DB2188][808] test_name - error
  → Labels: AT, Patron, degrade

Scenario 2: Same Error Continues (FAIL → FAIL, same)
  V808: FAIL (error A) → MA-12345 created
  V809: FAIL (error A)
  → COMMENT on MA-12345:
    "Still failing in version 809 (Daily Build: DB2189)"
    + version info + logs

Scenario 3: Different Error (FAIL → FAIL, different)
  V809: FAIL (error A)

  → CREATE JIRA: [DEGRADE][MA][DB2189][810] test_name - error
  → Labels: AT, Patron, degrade
